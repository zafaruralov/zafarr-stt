Upload a recording or speak into the mic. The audio goes into a queue on my Kubernetes cluster, and a worker pod turns it into Uzbek text on CPU.

How it works

1 · APIFastAPI pod takes the file and returns a job id at once
2 · QueueRedis keeps jobs in line, so 10 files at once is fine
3 · WorkersONNX model on CPU; the autoscaler adds pods when busy
4 · ResultThe page asks /jobs/{id} until the text is ready

API: POST /transcribe with form field file → GET /jobs/{id} · source code

Model: NVIDIA FastConformer uz (CC-BY-4.0), 10.9% WER on FLEURS. Runs on a home cluster, so it may sometimes be offline.
